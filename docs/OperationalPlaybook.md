# Operational Playbook

This playbook provides structured templates and checklists for capturing operational knowledge in the Knowledge Management App. Each template can be used as the basis for a new entry. The intent is to standardize how teams record events, decisions, and learnings so that the data remains useful over time.

## How to use

1. Pick a template that matches the situation.
2. Fill the prompts into a new `kmapp add` command.
3. Tag entries consistently so that lists and filters remain reliable.
